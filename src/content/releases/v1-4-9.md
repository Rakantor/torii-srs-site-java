It’s been a while since the last release – over **five years**, in fact! This update is a small one, but an important one. Most of the work went into updating dependencies for better security, improving stability, and making sure everything runs smoothly on **Apple Silicon Macs**.

### Breaking changes

- Android: Minimum version is now **7.0** (up from 4.4).

### Improvements

- Desktop: The app no longer needs a separate Java Runtime Environment (JRE). If you installed one just for Torii, you can safely remove it.
- Android: Fixed an issue where the top bar could be obscured by the screen cutout on some devices
- UI/UX: Fixed several typos and improved the clarity and readability of various dialogs
- Added a handful of small quality-of-life tweaks
- Minor bug fixes and code clean-ups
